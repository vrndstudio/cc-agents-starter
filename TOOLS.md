# Tools installed by `setup.sh`

One line each. Latest versions at install time; `verify.sh` shows which.

| Tool | What it does |
|------|--------------|
| `rg` (ripgrep) | Searches file contents for text, much faster than `grep`. |
| `fzf` | Interactive fuzzy finder for picking files or lines from a list. |
| `jq` | Reads and edits JSON on the command line; the status line uses it. |
| `fd` (`fdfind`) | Finds files by name, a faster and simpler `find`. |
| `shellcheck` | Lints bash scripts for bugs and bad practices. |
| `shfmt` | Formats bash scripts consistently. |
| `trash` (trash-cli) | Moves files to a trash folder instead of deleting them for good. |
| `nano` | Small terminal text editor, for editing settings via `sbx exec`. |
| `corepack` | Node's package-manager manager; installs and pins pnpm. |
| `pnpm` | Node package manager, faster and stricter than npm. |
| `ast-grep` | Searches and rewrites code by syntax structure rather than plain text. |
| `oxlint` | Fast JavaScript/TypeScript linter, an eslint replacement. |
| `oxfmt` | Fast JavaScript/TypeScript formatter, a prettier replacement. |
| `prek` | Runs git pre-commit hooks, a faster pre-commit replacement. |
